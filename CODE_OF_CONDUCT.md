# Code of conduct

## Our standards

Project spaces should stay welcoming, professional, and useful. Participants are expected to:

- discuss ideas and code without personal attacks
- respect different viewpoints and experience levels
- give feedback tied to the work and its impact
- protect private information and unpublished standards material
- accept that maintainers may close, move, or edit issues to keep discussions focused

Harassment, threats, discriminatory language, sexual attention, deliberate disruption, and publication of private information are not acceptable.

## Scope

This policy applies to repository issues, pull requests, discussions, commits, and other spaces used to coordinate the project.

## Reporting

Report concerning behavior to the project maintainers. If a public report could expose someone to risk, use GitHub's private reporting option when it is available and include enough detail for the maintainers to investigate.

Reports should include links, relevant context, and a description of the impact. Do not include credentials or confidential documents.

## Enforcement

Maintainers may edit or remove content, issue a warning, restrict participation, or block a contributor when behavior violates this policy. Decisions should be proportional to the conduct and explained when appropriate.
