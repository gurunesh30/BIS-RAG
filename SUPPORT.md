# Support

This repository does not provide a guaranteed response time. Public issues are best for reproducible bugs and concrete feature requests.

## Before opening an issue

- Search existing issues for the same symptom or request.
- Remove API keys, credentials, private PDFs, and personal data from logs and screenshots.
- Record the Python, Bun, browser, and operating system versions when they affect the problem.
- Include the command you ran and the smallest set of steps that reproduces the issue.

## Where to ask

- Use the bug report form for broken behavior.
- Use the feature request form for a proposed product change.
- Open a regular issue with a `question:` title for setup or usage questions when Discussions are unavailable.

For security concerns, follow `SECURITY.md` instead of posting sensitive details in a public issue.
